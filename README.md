### 🏭 FYP — Modbus Honeypot: Water Treatment Plant Simulator
> *Final Year Project — A realistic ICS honeypot simulating a water treatment plant via Modbus TCP, designed for security research, IDS/IPS testing, and attack pattern analysis*

[![Repo](https://img.shields.io/badge/GitHub-FYP_ModbusHoneypot-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Viishnu07/FYP_ModbusHoneypot_Water_Treatment_Plant)
![Stack](https://img.shields.io/badge/Stack-Python%20%7C%20Flask%20%7C%20Docker%20%7C%20Modbus-00FF88?style=for-the-badge)

| Component | Details |
|---|---|
| 🎯 **High-Interaction Modbus Server** | Fully writable holding registers on TCP port 502, mimicking a real PLC |
| 📊 **Live HMI Dashboard** | Flask web interface with real-time process variable monitoring (2s refresh) |
| 💧 **8 Process Variables** | Water level, pump status, flow rate, pressure, turbidity, chlorine & more |
| 📝 **Full JSON Audit Logging** | Every Modbus read/write logged with client IP, timestamp & register name |
| ⚔️ **Attack Scripts Included** | Kali-ready scripts: `modbus_read.py`, `modbus_attack.py`, `hmi_test.py` |
| 🐳 **Docker-Based Deployment** | One-command setup, isolated services, easy teardown |
| 🔬 **Research Use Cases** | ICS training, SIEM detection testing, anomaly detection research |
